# World Weather Map 

An interactive web based GIS application that displays real-time-weather condition for any location in the world. Click anywhere on the map to view the temperature and weather condition.

## Features
- Interactive flat map of the world powered by leaflet.js
- Real time weather of the world with open-meteo API 
- Toggle between temp and weather condition

## Technologies Used
- HTML, CSS , JS 
- Leaflet.js for interactive map
- Open Meteo API for weather data

## How to Run
Clone the Repo and start the live server 
- NO API needed to run this
